# PRODUCT SPECIFICATION — COZY CODE CORNER

## 1. Product Summary
Cozy Code Corner is an intelligent personal DSA learning, coding, and CS interview preparation platform designed around cognitive science, active retrieval, and deliberate practice.

## 2. Core Pillars
1. **The 12-Week NeetCode 150 Curriculum**:
   - Complete sequential roadmap covering Arrays & Hashing through Dynamic Programming, Graphs, and Advanced Algorithms.
2. **Pedagogical 6-Step Loop**:
   - Step 1: Read & Rephrase in your own words.
   - Step 2: Concrete Examples & Edge Case identification.
   - Step 3: Brute Force analysis.
   - Step 4: Algorithmic Invariant & Pattern trigger line.
   - Step 5: Clean Implementation in Python, Java, or C++.
   - Step 6: Mathematical Big-O Complexity proof.
3. **The 20-Minute Productive Struggle Rule**:
   - Timer encourages genuine problem-solving struggle.
   - Discourages immediate answer lookups.
4. **4-Tier Socratic Stuck Mode**:
   - Tier 1: Conceptual Socratic Nudge (clarifying question).
   - Tier 2: Pattern / Data Structure Clue (which invariant applies).
   - Tier 3: Ordered Algorithm Steps (pseudo-code without syntax).
   - Tier 4: Reference Implementation (triggers automatic Day 3 re-solve).
5. **Day 3 / 7 / 30 Spaced Retention System & The Blank Page Law**:
   - Solving a problem once is not learning it.
   - On Day 30, the user re-solves on a blank page with zero notes or hints.
   - Failure on any revision cycle resets the problem back to the Day 3 queue.
6. **CS Fundamentals & System Design**:
   - Curated modules in OOP, DBMS, SQL, Operating Systems, Networks, and Software Engineering.
   - 10 architectural principles and 5 end-to-end scalable case studies.
7. **Genuine Metacognitive Analytics**:
   - Tracks pattern autonomy, struggle duration, and Day 30 retention clearance rather than superficial problem counts.
